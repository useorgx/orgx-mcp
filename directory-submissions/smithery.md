# Smithery

Title:
OrgX MCP — Organizational Continuity for AI Agents

Short description:
OrgX keeps decisions, work state, and proof available across agent sessions. Resume work with scoped context, track blockers, and inspect receipts instead of relying on a chat's completion claim.

Current capabilities:
- Bootstrap workspace or initiative context; read supported material changes with orgx_tail. Change coverage is bounded, not a complete activity stream.
- Search decisions and artifacts, track plans and agent work, and attach proof to durable records.
- Review decisions through human-session links. MCP does not approve or reject decisions on the user's behalf.
- Use interactive widgets in MCP Apps-compatible hosts; other hosts receive structured tool responses.

Access:
Requires an OrgX account and authenticated workspace. OAuth scopes and the selected tool profile determine access. Write and delegation tools can change workspace state or dispatch work.
